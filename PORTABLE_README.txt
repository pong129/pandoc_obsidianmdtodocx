옵시디언 문서 변환기

ObsidianToDocx.exe를 실행하세요. Python, Word, PowerPoint 설치는 필요하지 않습니다.
pandoc.exe가 같은 폴더에 있으면 바로 변환할 수 있습니다.
Pandoc이 없으면 앱 위쪽의 'Pandoc 설치/업데이트'를 눌러 포터블 파일을 준비하세요.
최신 버전 확인이나 다운로드에는 인터넷이 필요합니다. 준비한 뒤 변환은 오프라인으로 동작합니다.

1. 왼쪽에서 파일 열기 또는 폴더 열기를 누르거나 Markdown 파일/폴더를 끌어다 놓습니다.
   폴더의 하위 폴더도 가져오며 .obsidian, .git 등의 관리 폴더는 제외합니다.
2. 오른쪽에서 Word 문서(DOCX) 또는 PowerPoint 발표(PPTX)를 선택합니다.
   형식을 바꿔도 가져온 파일 목록은 유지됩니다.
3. 영문, 한국어, 티베트어 글꼴과 크기를 정합니다.
   제목과 각주의 한국어/티베트어 크기는 각 언어의 본문 크기 비율로 적용합니다.
4. 자주 쓰는 서식은 '서식 저장'으로 이름을 붙여 저장할 수 있습니다.
5. 저장 탭에서 위치를 정하고 변환합니다. 같은 이름의 결과가 있으면 번호를 붙여 보존합니다.

PPTX에서는 레이아웃 탭에서 새 슬라이드를 만들 제목 단계를 선택합니다.
기본값은 제목 2(##)입니다. 긴 내용은 Markdown 제목으로 나누세요.
상위 제목은 본문과 같은 슬라이드에 배치합니다. 연속된 제목도 같은 슬라이드에 배치합니다.
PPTX 기본 본문 크기: 티베트어 20pt, 한국어 18pt.
본문 자동 분할은 기본으로 켜져 있습니다. 설정한 글꼴과 크기로 변환할 때마다 계산합니다.
티베트어 원문과 이어지는 한국어 번역을 함께 다음 슬라이드로 넘깁니다.
원문·번역 한 묶음 자체가 한 장보다 길면, 자동 축소하거나 번역을 분리하지 않고 해당 본문을 알려 변환을 중단합니다.
묶음은 Markdown 문단 순서로 판단합니다. 표 행이나 그림의 내용을 자동으로 나누지는 않습니다.

글꼴은 결과를 여는 컴퓨터에도 설치되어 있어야 정확히 표시됩니다.
Monlam 등의 글꼴은 사용자가 설치한 글꼴 목록에서 선택하세요.

설정과 프리셋은 EXE 옆 ObsidianConverter.ini에 저장됩니다.
앱 폴더에 쓰기 권한이 없으면 사용자 LocalAppData의 ObsiDeck 폴더를 사용합니다.
앱 폴더를 옮길 때 INI 파일을 함께 가져가면 설정을 유지할 수 있습니다.

DOCX를 Markdown으로 되돌리는 기능은 아래쪽 'DOCX → Markdown 도구'에 있습니다.
변환 실패나 Pandoc의 주의 사항은 '작업 로그 보기'에서 확인하세요.

지원 범위: 일반 Markdown 문서. Obsidian 플러그인 전용 문법, 노트 전개/임베드,
Dataview 결과 등은 해당 플러그인이 렌더링한 모습 그대로 변환하는 기능이 아닙니다.
